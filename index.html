theatr.us for PixInsight

This repository publishes the Foraxx Palette Utility, a script that builds a Foraxx palette image (or a plain SHO, HOO, HSO or OHS mapping) from stretched, starless narrowband images, with an optional stars image, channel gains and the standard Foraxx curves. Version 2 runs on the V8 JavaScript runtime in PixInsight 1.9.4 and later; the original 1.16 is still served to PixInsight 1.8.9-3 through 1.9.3.

The original script was written and published by Paul Hancock (Paulyman Astro). The Foraxx palette and its dynamic PixelMath expressions come from The Coldest Nights.

Add this repository in PixInsight

https://pixinsight.theatr.us/

How to install

  1. In PixInsight, open Resources → Updates → Manage Repositories.
  2. Add the URL above, including the trailing slash, and close the dialog.
  3. Run Resources → Updates → Check for Updates, accept the update, and restart PixInsight.
  4. Find the script under Script → theatr.us → Foraxx Palette Utility.

The address https://pixinsight.psf-guard.com/ from before September 2026 still works and serves the same files.

The scripts are not code-signed, so PixInsight prints a warning in the console the first time each runs. That is expected.
